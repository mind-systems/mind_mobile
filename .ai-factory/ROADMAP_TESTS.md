- [x] **BreathModuleStateChannel — instruction dispatch and flush** — extend `test/BreathModule/breath_module_state_channel_test.dart` (created in previous milestone) with three more test groups. (1) **instruction dispatch** — phase change while `status=breath` and `moduleSessionId` available calls `_instructionStream.sendSample(moduleSessionId, phase.name, currentIntervalMs)`; exerciseIndex change with same phase also triggers send; no change in either field does not trigger send; `status=pause` suppresses send; `_started=false` suppresses send; `_ended=true` suppresses send. To make `moduleSessionId` available: emit a `ModuleState(moduleSessionId: "sid")` on `_FakeChannel.stateController`. (2) **pending flush** — phase change while `moduleSessionId=null` stores state in `_pendingInstruction` and does not call `sendSample`; subsequent `ModuleState` emission with a non-null `moduleSessionId` flushes it and calls `sendSample` exactly once; a second flush with the same id does nothing (buffer cleared); if `moduleSessionId` arrives before any phase change, no `sendSample` is called. (3) **reset and dispose** — `reset()` zeroes all private fields (`_started`, `_ended`, `_moduleSessionId`, `_previousStatus`, `_previousPhase`, `_previousExerciseIndex`, `_pendingInstruction`) but subscriptions remain alive (emitting a state after reset triggers lifecycle again); `dispose()` calls `channel.stop()` when `_started && !_ended`, does not call `channel.stop()` if never started, does not call `channel.stop()` if already ended, and cancels both `_stateSub` and `_channelSub`. - [ ] **`BreathSessionState.equalsIgnoringTickFields` truth table** — no test file exists for `packages/breath_module/lib/src/BreathSession/Models/BreathSessionState.dart`. Create `test/BreathModule/Presentation/BreathSession/breath_session_state_equality_test.dart`. Write a `_state({...})` helper that returns a fully-populated `BreathSessionState` with all required fields set to fixed non-default values (so any single field flip is observable). Test groups: (1) **excluded fields return true** — for each of `remainingTicks` and `currentIntervalMs`, build two states differing only in that field and assert `a.equalsIgnoringTickFields(b) == true`; (2) **included scalar fields return false** — for each of `loadState`, `status`, `phase`, `exerciseIndex`, `activeStepId`, `isStarred`, `canStar`, `resetReason`, `totalPhases`, `currentPhaseIndex`, `currentPhaseTotalDuration`, `currentExerciseShape`, `nextExerciseShape`, `tickSource`, build two states differing only in that field and assert returns `false`; (3) **`timelineSteps` identity semantics** — same `List<TimelineStep>` reference → returns `true`; two distinct lists with identical content → returns `false` (the `identical(...)` check is intentional and load-bearing; this test pins it so any future swap to `listEquals` fails loudly).

- [ ] **`BreathViewModel` dual-channel publication and tick-cadence filter** — no view-model-level test for the `set state` filter exists. Create `test/BreathModule/Presentation/BreathSession/breath_view_model_publication_test.dart`. Reuse the fake pattern from `breath_session_star_toggle_test.dart` (`_FakeTickService`, `_FakeCoordinator`, `_FakeSessionService`) — copy them inline. Test groups: (1) **Riverpod publication is filtered on tick-only updates** — call `vm.initState()` and pump async; install a counting listener via `container.listen<BreathSessionState>(breathViewModelProvider, (_, __) => count++, fireImmediately: false)`; drive several `tickService.tick()` calls that only advance `remainingTicks` (no phase change) and assert `count == 0`; trigger a phase boundary (more ticks until phase flips) and assert `count` increments by exactly 1; (2) **raw `vm.stream` fires on every update including tick-only** — subscribe to `vm.stream`, repeat the same tick sequence, assert subscriber received one event per tick regardless of structural change; (3) **`remainingTicksNotifier` advances on every tick independent of Riverpod** — attach a listener to `vm.remainingTicksNotifier`, repeat the same tick sequence, assert the listener fired on each tick where the value changed and `notifier.value` matches the latest `engineState.remainingTicks`.

- [ ] **`BreathViewModel._onEngineState` preserves `timelineSteps` identity across ticks** — regression guard for the load-bearing invariant that `BreathSessionState.equalsIgnoringTickFields` depends on (`identical(timelineSteps, other.timelineSteps)` in the `set state` filter). Extend `test/BreathModule/Presentation/BreathSession/breath_view_model_publication_test.dart` (or create it if the previous milestone hasn't shipped yet) with one test group: **timelineSteps identity** — after `vm.initState()` completes, capture `final captured = vm.currentState.timelineSteps;`; drive several `tickService.tick()` calls; after each tick assert `identical(vm.currentState.timelineSteps, captured) == true`; then call `vm.restartEngine()` and assert `identical(vm.currentState.timelineSteps, captured) == false` (a new list is built only by `_setupEngine`). Failure of this test means a future change to `_onEngineState` started rebuilding the list per tick and silently defeated the Riverpod publication filter.
