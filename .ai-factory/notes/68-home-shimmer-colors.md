# Fix Invisible Shimmer Colors on HomeScreen

**Date:** 2026-06-02
**Source:** conversation context

## Key Findings

- `_SuggestionsShimmer` and `_StatsShimmer` use `colorScheme.surfaceContainerHighest` / `colorScheme.surface` — neither is set in `AppTheme`, so Flutter auto-generates values near-identical to the scaffold background, making shimmer containers invisible.
- The correct colors are `theme.cardColor` (base) and `theme.highlightColor` (sweep) — explicitly defined in `AppTheme` for shimmer and already used by `BreathSessionListSkeletonCell`.
- Confirmed visually on device: shimmer appears as a white rectangle with a faint border instead of an animated shimmer.

## Details

### Problem

Both shimmer widgets set colors from:
```dart
final base      = theme.colorScheme.surfaceContainerHighest;
final highlight = theme.colorScheme.surface;
```

`AppTheme` only sets `surface` (= scaffold background `_kBackgroundDark`/`_kBackgroundLight`). `surfaceContainerHighest` is auto-generated by Flutter from the seed color and ends up nearly identical to `surface`. Result: shimmer containers (`color: base`) are invisible against the background.

### Fix

In both shimmer widgets replace the two color lines:
```dart
final base      = theme.cardColor;
final highlight = theme.highlightColor;
```

`AppTheme` (`packages/mind_ui/lib/src/AppTheme.dart`) defines:
- `cardColor`      → `_kCardDark` (`0xFF1A2433`) / `_kCardLight` (`0xFFE8EDF5`)
- `highlightColor` → `_kShimmerHighlightDark` (`0xFF2A3A50`) / `_kShimmerHighlightLight` (`0xFFD0D8E8`)

### Files to change

| File | Location |
|------|----------|
| `lib/HomeModule/Presentation/HomeScreen/Widgets/SuggestionsCard.dart` | inside `_SuggestionsShimmer.build()` |
| `lib/HomeModule/Presentation/HomeScreen/Widgets/StatsCard.dart` | inside `_StatsShimmer.build()` |

Two files, two lines each — no structural changes.

### Reference

`BreathSessionListSkeletonCell` (`packages/breath_module/lib/src/BreathSessionsList/Views/BreathSessionListSkeletonCell.dart`) uses the same pattern and is visually correct.

## Verify

Launch app while gRPC server is unreachable (shimmer persists because `isXxxLoading` stays `true`). Both HomeScreen shimmer areas must show a visible animated shimmer matching the BreathSessionList skeleton style.
